# 📰 Daily News

Daily News is a modern and responsive news portal website built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**. Users can browse the latest news in a clean card-based layout and click on any news card to read full details.

---

## 🚀 Features

- 📰 Display news in responsive card layout
- 📄 Dynamic news details page
- 🌙 Dark & Light mode support
- 🔍 Category based filtering
- ⚡ Fast performance with Next.js
- 🎨 Beautiful UI using shadcn/ui
- 📱 Fully responsive design
- 🔥 Built with TypeScript for type safety

---

## 🛠️ Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
